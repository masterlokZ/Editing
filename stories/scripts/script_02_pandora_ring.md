# 剧本卡片：柜台前颤抖的130美元银戒

- **真实背景**：推特轰动全美、引发数百万人声讨的 Ariel McRae 结婚戒指事件。
- **表面载体（银）**：商场珠宝柜台里一枚标价 130 美元（几百块钱）、镶嵌人造锆石的 925 银戒指。
- **隐秘真相（金）**：男孩日夜兼职两份工、顿顿吃泡面攒下的全部积蓄，以及女孩对虚荣世界最决绝的反击。
- **情感基调**：压抑后的爆发、直击现实痛处、坚定与尊严。
- **配乐参考**：开场极低沉压抑的钢琴单音，中段加入提琴与呼吸声，结尾转为明亮而有力量的弦乐。
