# 剧本卡片：二手店2美元破熊里的母亲心跳

- **真实背景**：推特轰动全球的二手店录音泰迪熊跨国寻人真实事件。
- **表面载体（银）**：旧货店货架上标价 2 美元、掉毛发黄、被当成废品处理的破旧毛绒熊。
- **隐秘真相（金）**：一位临终年轻母亲在病床上为年幼女儿留下的绝版心跳与最后遗言。
- **情感基调**：温柔、酸楚、失而复得的巨大震撼。
- **配乐参考**：空灵清澈的八音盒旋律，中段逐渐加入温暖平缓的钢琴与大提琴，混入微弱平稳的监护仪心跳声。
